为什么选择 Lumen Switcher？

🎙️ 静音与静止切片

主界面勾选即可：只勾静音按声音切，只勾静止按画面切，两项都勾则必须有声且有画面才保留。阈值和前后留白在设置里调。

🔇 本地脏话消音

可选功能。语音在本机识别，只匹配你设置里的词表（可中英日韩西混排）。可消音或只在波形上标粉，不上传素材。

⚡ 极速无损 Remux 导出

对于数小时的会议录像或直播回放，直接在关键帧处切断拼接，免去漫长的重编码时间，几秒钟输出成片。

🎯 帧级精准 Re-encode

硬件级逐帧解码与压制，精准对齐语音起始毫秒，并自动保留自然说话气声与尾音边距 (Padding)。

🎞️ FCPXML 非破坏性工作流

一键导出 FCPXML。支持“物理剔除”或将废片标记为“禁用状态”，方便剪辑师在达芬奇或 FCPX 中二次复核。

🔒 绝对隐私与安全

100% 本地运算。视频文件从不出你的电脑，无须上传云端服务器，保障未公开商业素材与私人录像的安全。

💻 跨平台软硬件优化

专为 Windows (Media Foundation) 与 macOS (VideoToolbox / CoreMedia) 深度调优，极致节省 CPU 负载。
