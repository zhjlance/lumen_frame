Lumen Switcher 官方用户使用手册

欢迎使用 Lumen Switcher。这是一款基于原生 C++ 核心引擎打造的桌面级视频粗剪与智能切片工具，旨在为您跳过繁琐的“挑素材”阶段，直接生成可用的时间线，完美衔接专业级 NLE (非线性编辑) 软件。

1. 产品简介

Lumen Switcher 摈弃了传统剪辑软件臃肿的架构，采用极简的交互逻辑：拖入素材 → 设定阈值 → 智能扫描 → 导出工程。无论是长达数小时的直播回放录像，还是海量的会议视频，它都能在极短时间内剔除无效片段。

2. 媒体导入与兼容性

  • 格式支持：全面兼容市面主流媒体容器，包括 .mp4, .mov, .mkv, .avi 以及广播级 .ts 格式。
  • 底层解码：内建 FFmpeg 与 OpenCV 硬件加速支持，无论 H.264、HEVC(H.265) 还是 ProRes 均可流畅解析。
  • 操作方式：直接将文件拖拽至应用主界面，引擎将自动提取视音频基础属性及分辨率信息。

3. 多模态双轨分析引擎

点击 "Render & Analyze" 后，Lumen Switcher 将启动双模态分析机制：

  • Silence Gate (静音过滤)：自动探测音轨电平，低于设定阈值（默认 -35.0 dB）的持续片段将被判定为无效。
  • Motion Gate (动态过滤)：逐帧比对画面差异，剔除长时间静止无变化的废片。
  • 交互式波形图：分析完成后，下方将生成高精度的音频波形图。您可以双击任意片段进行手动反转操作。

4. 高级导出与工作流接入

我们提供两种截然不同的交付路径，满足不同精度的制作需求：

  1. 导出 FCPXML (强烈推荐)：一键生成 Final Cut Pro XML 协议文件。您可以将其直接导入至 DaVinci Resolve (达芬奇)、Final Cut Pro 或 Premiere Pro 中，所有切点会以非破坏性时间线的形式完美还原。
  2. 导出物理 MP4 实体文件：
    • Fast Mode (极速重封装模式)：直接在关键帧处对视频流进行切割并无缝拼接，速度极快。
    • Precise Mode (精准重编码模式)：逐帧解码并重新压制，确保每一帧切点绝对精准。

5. 试用期与设备授权管理

Lumen Switcher 为所有用户提供良心的试用机制，并采用高安全性“一机一码”硬件绑定策略：

  • 30天无限制试用：首次下载安装后，您可以免费体验 30 天的完整导出功能。试用期结束后，需在官网购买永久 License 以继续使用。
  • 激活绑定：购买后在设置界面输入 License Key，系统将采集主板指纹进行硬件授权。卸载重装系统不影响授权有效性。
  • 换机与解绑：在激活状态下，点击解绑按钮即可释放当前设备名额，随后您可以在全新设备上再次激活。
