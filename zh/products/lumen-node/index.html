Lumen Node 官方用户使用手册

欢迎使用 Lumen Node。本应用专为广电制播与专业直播团队设计，旨在将您的移动设备转化为一台具备极低延迟、广播级稳定性的 SRT / RTSP 无线导播摄像机。本手册将详细介绍基础操作、专业监控工具以及业内首创的 Web 导演控制台。

1. 快速入门 (Quick Start)

  1. 连接网络：请确保手机与您的导播台（如 vMix, OBS）或 Web 监看设备连接在同一个局域网 (Wi-Fi) 下。
  2. 授权访问：首次启动时，请允许应用获取“相机”与“麦克风”权限。
  3. 一键开播：点击屏幕下方的 START LIVE 按钮，伴随 iOS 级原生阻尼动效，状态栏将切换为蓝色的 ON AIR，代表流媒体已开始在局域网内广播。
  4. 导播台接收：在 vMix 或 OBS 中添加 SRT 或 RTSP 信号源即可直接拉取极低延迟的纯净画面。

2. 界面与 HUD 监控系统

2.1 动态岛状态栏 (Dynamic Island)

屏幕顶部采用业内先进的悬浮动态岛设计：

  • 蓝色 LIVE 呼吸灯：网络推流处于激活状态 (ON AIR)。
  • 红色 REC 呼吸灯：本地 ISO 高画质录制处于激活状态 (RECORDING)。

2.2 Tally 演播室指引系统

深度集成演播室级别的 Tally 联动，屏幕边框将根据导播台的操作实时变换颜色：

  • 无边框：机位处于待机。
  • 绿框 (PVW)：您的画面已被切入导播台预览区，即将播出。
  • 红框 (PGM)：您的画面正在正式播出。

3. 专业影像控制

  • 触控对焦：单击屏幕，摄像机会自动对该区域测光并对焦。
  • 3A 物理锁定：左侧提供 AF-L (对焦), AE-L (曝光), AWB-L (白平衡) 的硬件级锁定开关。
  • 曝光与辅助工具：底部提供 -3.0 到 +3.0 无级曝光滑动条。点击左侧设置图标可开启斑马纹 (Zebra) 和 峰值对焦 (Peaking)。

4. 网络流与多协议并发

Lumen Node 采用纯正 C++ 底层构建，支持双协议并发零拷贝分发：

  • 硬件帧率锁定 (Hardware CFR)：强制锁定传感器输出为 30 或 60 FPS，彻底杜绝手机暗光掉帧导致的“声画不同步”。
  • SRT 模式 (Caller)：跨公网的弱网抗抖动传输。格式如：srt://192.168.1.100:5000?mode=caller。
  • RTSP 模式：自动常驻局域网端口 8554，可用 vMix、OBS 或 VLC 等播放器直接拉取 rtsp://<手机IP>:8554/live。

5. 杀手级功能：局域网 Web 导演控制台

针对多机位外场直播或单兵作战，Lumen Node 内置了免安装的 Web 导演台。

使用方法：

  1. 确保控制端（电脑/iPad）与手机处于同一网络。
  2. 在浏览器地址栏输入：http://<手机IP>:8080。
  3. 实时图传：网页将以极低 CPU 占用的 MJPEG 协议实时显示摄像机监控画面。
  4. 双向状态穿透：在网页点击 START LIVE 或 START REC，手机端不仅会立即执行硬件指令，其动态岛 UI 也会毫无延迟地同步变换状态！

6. 跨平台远程反向控制 (RESTful API)

所有 Web 导演台的功能均开放了 REST API，方便您接入 Companion 或 vMix 宏脚本（端口 8080）：

  • 推拉变焦：/api/control?action=zoom&value=<1.0/3.0>
  • 曝光补偿：/api/control?action=exposure&value=<-1.5/2.0>
  • 启停推流：/api/control?action=stream&value=<0/1>
  • 启停录制：/api/control?action=record&value=<0/1>
  • 状态轮询：/api/state (返回 JSON 格式的软硬件状态)

7. Pro 版说明

免费版提供完整的工业级制播体验，但画面底部附带水印，且单次连续推流上限为 15 分钟。点击 UI 右上角的 "TRIAL" 按钮升级至 PRO 版，即可彻底解除限制，享受 7x24 小时无间断输出。
