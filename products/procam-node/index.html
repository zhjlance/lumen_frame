ProCam Node 官方用户使用手册

欢迎使用 ProCam Node。本应用专为广电制播与专业直播团队设计，旨在将您的 Android 设备转化为一台具备极低延迟、广播级稳定性的 NDI / SRT 无线导播摄像机。本手册将详细介绍基础操作、专业监控工具以及高级的跨平台远程控制（RESTful API）功能。

1. 快速入门 (Quick Start)

1.1 基础连接

  1. 连接网络：请确保手机与您的导播台（如 vMix, OBS, Tricaster）连接在同一个局域网 (Wi-Fi) 下。
  2. 授权访问：首次启动时，请允许应用获取“相机”与“麦克风”权限。
  3. 一键开播：点击底部中央的 LIVE 按钮。按钮变红即代表流媒体已开始在局域网内广播。
  4. 导播台接收：在 vMix 或 OBS 中添加 NDI 信号源，选择名为 ProCam_Android_Live（或您在设置中自定义的名称）的机位即可。

2. 界面与 HUD 监控系统

ProCam Node 提供了全面且专业的屏幕监控体系（HUD），所有参数一目了然：

2.1 顶部状态栏

  • Tally 状态：显示当前机位状态（详见 2.2 Tally 演播室指引）。
  • 实时流数据：实时显示当前输出帧率（FPS）与编码码率（Mbps）以及丢包率（L: 0.0%）。
  • 硬件健康度：
    • B: 电池剩余电量。
    • W: Wi-Fi 信号强度（dBm）。低于 -70dBm 时变红，提示网络可能存在抖动。
    • WARM / HOT: 内部主板温度监控。当设备过热时会出现红色警告，请注意设备散热。

2.2 Tally 演播室指引系统

本应用深度集成了 NDI Advanced Tally 协议，屏幕边框将根据导播台的操作实时变换颜色，方便摄像师确认机位状态：

  • 无边框 (STANDBY / LIVE)：机位处于待机或推流中，但导播台未选用您的画面。
  • 绿框 (PVW - Preview)：您的画面已被切入导播台的预览区（下一个画面即将切给您，请摄像师稳住镜头）。
  • 红框 (PGM - Program)：您的画面正在正式播出（观众正在看着您）。

3. 专业影像控制

点击屏幕任意位置可唤出 UI 面板。在专业直播中，画面的忽明忽暗和反复对焦是致命的。

  • 触控对焦：单击屏幕画面中的任意物体，摄像机会自动对该区域进行测光并对焦。
  • AF-L / AE-L / AWB-L：左侧提供 自动对焦 (AF)、自动曝光 (AE) 和 自动白平衡 (AWB) 的物理锁定开关。点击变红即代表锁定当前参数，防止被闲杂人员走动干扰。
  • EV 曝光补偿：底部提供 -2.0 到 +2.0 的无级曝光补偿拨杆。

3.2 辅助监看工具 (Assist Tools)

点击左下角的快捷参数按钮（三点图标）可唤出辅助工具：

  • 斑马纹 (Zebra)：高亮显示画面中严重过曝（死白）的区域，帮助您精准控制曝光。
  • 峰值对焦 (Peaking)：用红色高亮显示画面中焦平面最清晰的物体边缘，确保对焦绝对锐利。
  • 镜头切换 (Lens)：支持前置 / 后置摄像头无缝切换。

4. 网络流与编码设置 (Settings)

4.1 硬件帧率锁定 (Hardware CFR)

ProCam Node 使用严格的硬件恒定帧率（CFR）管线。您可以强制锁定传感器输出为 30 FPS 或 60 FPS，彻底杜绝普通手机软件在暗光下自动掉帧导致的“声画不同步”问题。

4.2 NDI 与 SRT 双模推流

我们采用了高兼容性的 H.264 (AVC) 硬件编码底层，确保与所有新老导播台 100% 兼容。

  • NDI 模式：适用于局域网低延迟导播。可自定义 NDI 通道名称。
  • SRT 模式 (Caller)：适用于跨公网/外网的异地连线。请在输入框中填写目标 Listener 的地址，格式如：srt://192.168.1.100:5000?mode=caller。

(注：NDI 和 SRT 可同时开启，实现内网导播与异地监看的双轨并发。)

4.3 本地无损录像 (Local ISO)

点击右侧的 REC 按钮，应用会在推流的同时，将极高画质的纯净 H.264 原始视频流转储至手机的 Movies/ProCamNode 目录。点击 SNAP 可拍摄全分辨率 RAW 级无损照片。

5. 高级功能：跨平台远程反向控制 (RESTful API)

针对演播室的固定机位、摇臂机位及无人值守场景，ProCam Node 内置了原生的微型 HTTP 控制网关。导播无需触碰手机，即可通过局域网远程控制手机的硬件马达！

控制前提：控制台与手机处于同一局域网内。
控制端口：8080

5.1 API 接口列表

  • 1. 镜头推拉变焦 (Zoom)
    URL: http://<手机IP>:8080/api/control?action=zoom&value=<倍数>
    说明: 控制物理镜头变焦。1.0 为原焦距，2.0 为 2倍放大。
  • 2. 曝光补偿调节 (Exposure)
    URL: http://<手机IP>:8080/api/control?action=exposure&value=<EV值>
    说明: 远程增减画面亮度。支持负数（如 -1.0）和正数（如 1.5）。
  • 3. 远程启停推流 (Stream Toggle)
    URL: http://<手机IP>:8080/api/control?action=stream&value=<状态>
    说明: 紧急掐断或恢复推流。0 代表停止，1 代表开始。

5.2 演播室实战集成案例 (vMix & Companion)

您可以将上述 API 完美集成到传统导播工作流中：

在 vMix 中绑定快捷键：打开 vMix Settings -> Scripting，新建一个脚本，仅需粘贴一行代码（注意替换为手机真实 IP）：

(New System.Net.WebClient()).DownloadString("http://192.168.0.138:8080/api/control?action=zoom&value=2.0")

保存后，在 Shortcuts 中将此脚本绑定到键盘的 + 号键。导播按下 + 键，远处手机即可瞬间推近。

在 Stream Deck (Bitfocus Companion) 中：直接添加一个 Generic HTTP Request 动作，Method 选 GET，将上述 URL 填入即可实现硬件按钮远程遥控。

6. Pro 版与试用限制说明

ProCam Node 免费版提供完整的专业制播体验，但存在以下限制：

  1. 画面底部带有水印。
  2. 连续推流时长上限为 15 分钟。到达时限后，系统将自动切断视频流并在手机端显示黑屏警告。

解锁专业版 (PRO)：您可以通过点击 UI 面板右上角的 "UPGRADE TO PRO" 进行应用内订阅/买断。解锁后将彻底去除水印、解除所有时间限制，享受 7x24 小时无间断工业级制播体验。
