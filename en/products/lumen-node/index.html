Lumen Node Official User Manual

Welcome to Lumen Node. Designed for broadcast production and professional live-streaming teams, this app transforms your mobile device into an ultra-low latency, broadcast-grade wireless studio camera. This manual details basic operations, monitoring tools, and the industry-first Director's Web HUD.

1. Quick Start

  1. Network: Ensure your phone and switcher (e.g., vMix, OBS) or Web monitor are on the same local network (Wi-Fi).
  2. Permissions: Grant "Camera" and "Microphone" permissions upon first launch.
  3. Go Live: Tap the START LIVE button. With a smooth iOS-style animation, the dynamic island will show a blue ON AIR indicator, meaning the stream is live.
  4. Receiving: Add an NDI/SRT/RTSP source in vMix/OBS to pull the pristine, low-latency feed.

2. Interface & HUD Monitoring System

2.1 Dynamic Island Status Bar

The top of the screen features a floating Dynamic Island design:

  • Blue LIVE Pulse: Network streaming is active (ON AIR).
  • Red REC Pulse: Local ISO high-quality recording is active (RECORDING).

2.2 Studio Tally System

Deeply integrated with the NDI Advanced Tally protocol, the screen borders change color in real-time based on switcher operations:

  • No Border: Camera is on standby.
  • Green Border (PVW): Your feed is in the switcher's Preview, about to go live.
  • Red Border (PGM): Your feed is currently live on air.

3. Professional Camera Control

  • Touch to Focus: Tap anywhere to meter and focus on a specific area.
  • 3A Hardware Lock: Physical lock switches for AF-L (Focus), AE-L (Exposure), and AWB-L (White Balance) on the left.
  • EV & Assist Tools: A stepless exposure slider (-3.0 to +3.0) at the bottom. Tap the settings icon to enable Zebra and Peaking.

4. Multi-Protocol Streaming

Built on a pure C++ core, Lumen Node supports zero-copy distribution across three concurrent protocols:

  • Hardware CFR Lock: Forces sensor output to 30 or 60 FPS, eliminating A/V sync issues caused by frame drops in low light.
  • NDI Mode: The industry standard for low-latency local broadcasting.
  • SRT Mode (Caller): For cross-WAN jitter-resistant transmission. E.g., srt://192.168.1.100:5000?mode=caller.
  • RTSP Mode: Automatically runs on local port 8554. Pull the feed directly using VLC via rtsp://<IP>:8554/live.

5. Killer Feature: Web Director's HUD

For multi-cam outdoor broadcasts or solo operations, Lumen Node includes a built-in, installation-free Web Director's Console.

How to use:

  1. Ensure your control device (PC/iPad) is on the same network as the phone.
  2. Open a browser and navigate to: http://<Phone_IP>:8080.
  3. Live Preview: The webpage displays real-time camera monitoring via an extremely low-CPU MJPEG stream.
  4. Bi-directional State Sync: Click START LIVE or START REC on the webpage. Not only will the phone instantly execute the hardware command, but its UI will seamlessly animate to the new state with zero delay!

6. RESTful API Remote Control

All Web HUD features are exposed via REST API (Port 8080), making it easy to integrate with Bitfocus Companion or vMix macro scripts:

  • Zoom: /api/control?action=zoom&value=<1.0/3.0>
  • Exposure: /api/control?action=exposure&value=<-1.5/2.0>
  • Toggle Stream: /api/control?action=stream&value=<0/1>
  • Toggle Record: /api/control?action=record&value=<0/1>
  • State Polling: /api/state (Returns a JSON payload of hardware/software status)
