ProCam Node Official User Manual

Welcome to ProCam Node. This application is designed for broadcast production and professional live-streaming teams, aiming to transform your Android device into an ultra-low latency, broadcast-grade NDI / SRT wireless studio camera. This manual details basic operations, monitoring tools, and advanced cross-platform remote control (RESTful API) features.

1. Quick Start

1.1 Basic Connection

  1. Network Connection: Ensure your phone and your switcher (e.g., vMix, OBS, Tricaster) are connected to the same local network (Wi-Fi).
  2. Permissions: Upon first launch, grant the app "Camera" and "Microphone" permissions.
  3. Go Live: Tap the central LIVE button at the bottom. The button turns red, indicating the stream is broadcasting over the LAN.
  4. Switcher Reception: Add an NDI source in vMix or OBS, and select the camera named ProCam_Android_Live.

2. Interface & HUD Monitoring System

ProCam Node provides a comprehensive professional Heads-Up Display (HUD):

2.1 Top Status Bar

  • Tally Status: Displays the current camera status.
  • Live Stream Data: Real-time display of FPS, encoding bitrate (Mbps), and packet loss rate (L: 0.0%).
  • Hardware Health:
    • B: Battery level.
    • W: Wi-Fi signal strength (dBm). Turns red below -70dBm indicating potential network jitter.
    • WARM / HOT: Motherboard temperature monitoring.

2.2 Studio Tally System

The app deeply integrates the NDI Advanced Tally protocol. The screen borders change color based on switcher operations:

  • No Border (STANDBY / LIVE): Camera is on standby or streaming, but not selected by the switcher.
  • Green Border (PVW - Preview): Your camera is in the switcher's Preview area (next to be cut).
  • Red Border (PGM - Program): Your camera is currently Live on air.

3. Professional Camera Control

Tap anywhere on the screen to bring up the UI panel.

  • Touch to Focus: Tap on any object to meter and focus on that specific area.
  • AF-L / AE-L / AWB-L: Physical lock switches for Auto Focus, Auto Exposure, and Auto White Balance. Lock these to prevent interference.
  • EV Compensation: A stepless exposure slider from -2.0 to +2.0 at the bottom.

3.2 Assist Tools

Tap the three-dot button at the bottom left to access assist tools:

  • Zebra: Highlights overexposed areas to help control exposure precisely.
  • Peaking: Highlights sharp edges in red to ensure perfect focus.
  • Lens Switch: Seamlessly switch between front and rear cameras.

4. Stream & Encoding Settings

4.1 Hardware CFR Lock

ProCam Node uses a strict hardware Constant Frame Rate (CFR) pipeline. You can lock sensor output to 30 FPS or 60 FPS to eliminate A/V sync issues caused by frame drops in low light.

4.2 NDI & SRT Dual Streaming

  • NDI Mode: For low-latency local network broadcasting.
  • SRT Mode (Caller): For cross-WAN/remote connections. Format: srt://192.168.1.100:5000?mode=caller.

(Note: Both can run simultaneously.)

4.3 Local ISO Recording

Tap REC to record a pure H.264 video stream to the Movies/ProCamNode directory while streaming. Tap SNAP for a full-resolution RAW photo.

5. Advanced: RESTful API Remote Control

ProCam Node features a built-in micro HTTP gateway for remote control over LAN.
Control Port: 8080

5.1 API Endpoints

  • Zoom
    URL: http://<IP>:8080/api/control?action=zoom&value=<Multiplier>
  • Exposure Compensation
    URL: http://<IP>:8080/api/control?action=exposure&value=<EV>
  • Stream Toggle
    URL: http://<IP>:8080/api/control?action=stream&value=<0_or_1>

6. Pro Version Limitations

The free version has a watermark and a 15-minute continuous streaming limit. Upgrade to PRO via the UI panel to remove all restrictions.
